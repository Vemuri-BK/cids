2. WHY THIS IS HAPPENING (ROOT CAUSE ANALYSIS)
--------------------------------------------------------------------------------

A. ROOT CAUSE 1: Soft Dice Background Dilution & BCE Over-Shrinkage
In scripts/s7_refine.py:
  p = torch.sigmoid(z)
  inter = (p * y).sum(); den = p.sum() + y.sum()
  loss = (1 - (2*inter + 1)/(den + 1)) + BCE(z, y)

- In the patch background where allow == 0 and m0 == 0, z = -ln(3) -> p = 0.25.
- In a 64^3 patch (262,144 voxels), ~200,000+ voxels are background.
- Those voxels inject an artificial 200,000 * 0.25 = 50,000 voxels into the Dice
  denominator (den = p.sum() + y.sum()).
- Consequence:
  1. The soft Dice term is artificially stuck at ~0.25 - 0.28, completely muting
     its gradient signal on boundary voxels.
  2. The unweighted BCE term dominates the training loss.
  3. Because standard BCE penalizes false positives and false negatives equally,
     and because the network cannot touch the background (allow == 0), the easiest
     way for the optimizer to drive loss from 0.65 to 0.43 is to slightly shrink
     the boundary voxels where the network is uncertain.
  4. This conservative boundary shrinkage drops true overlap, lowering validation Dice.

B. ROOT CAUSE 2: Mask Perturbation Over-Perturbs Boundaries
In cids/refine/data.py (perturb_mask):
- 80% of training masks are randomly grown, shrunk by up to 2 voxels, and wobbled
  with synthetic Gaussian noise.
- SegResNet-100 masks on training cases are already relatively accurate.
- When perturbed by +/- 2 voxels, the refiner spends its capacity learning to correct
  artificial Gaussian wobble rather than aligning with subtle high-frequency MRI gradients.
- When tested on validation cases (which have real image-guided boundaries, not synthetic
  wobble), the refiner's aggressive 1,800-voxel corrections hurt 28 cases while helping only 20.

C. ROOT CAUSE 3: Learning Rate (1e-3) Is Too Aggressive for Fine Refinement
- S7 starts from an already strong baseline (val Dice 0.7742).
- It only needs to refine subtle boundary contours.
- An initial learning rate of 1e-3 with AdamW causes large updates to delta logits,
  forcing boundaries to fluctuate too wildly (altering ~1,800 voxels per case).


3. EXACT CODE CHANGES TO FIX THE REFINEMENT EXPERIMENT
--------------------------------------------------------------------------------

FIX 1: Mask the Training Loss to the Active Boundary (allow > 0.5)
File: scripts/s7_refine.py
Replace dice_bce (lines 65-68):

```python
def dice_bce(z, y, allow):
    """Compute Dice + BCE strictly within the active allow band (|SDF| <= 8 voxels)."""
    mask = allow > 0.5
    if not mask.any():
        return torch.tensor(0.0, device=z.device, requires_grad=True)
    
    z_act = z[mask]
    y_act = y[mask]
    p_act = torch.sigmoid(z_act)
    
    # 1. Active boundary BCE
    bce = F.binary_cross_entropy_with_logits(z_act, y_act)
    
    # 2. Active boundary Soft Dice without background dilution
    inter = (p_act * y_act).sum()
    den = p_act.sum() + y_act.sum()
    dice_loss = 1.0 - (2.0 * inter + 1.0) / (den + 1.0)
    
    return dice_loss + bce
```

In main() (line 185 of scripts/s7_refine.py):
Replace:
    loss = dice_bce(z.float(), y)
With:
    allow = x[:, 5:6]
    loss = dice_bce(z.float(), y, allow)


FIX 2: Tame Mask Perturbation to Respect Real Contrast Margins
File: cids/refine/data.py
Replace perturb_mask (lines 67-76):

```python
def perturb_mask(m: np.ndarray, rng) -> np.ndarray:
    """Subtle boundary perturbation: keep 50% clean, and limit shift to +/- 1 voxel."""
    if not m.any() or rng.random() < 0.5:   # 50% clean out-of-fold masks
        return m
    sdf = signed_distance(m)
    noise = ndimage.gaussian_filter(rng.standard_normal(m.shape).astype(np.float32), sigma=rng.uniform(3, 5))
    noise *= rng.uniform(0.3, 1.0) / (noise.std() + 1e-6)
    out = (sdf + noise + rng.uniform(-1.0, 1.0)) < 0   # shift by at most 1 voxel (not 2)
    return out if out.any() else m
```
