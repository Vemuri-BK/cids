5. PRIORITY LEARNING CHANGES TO TEST
--------------------------------------------------------------------------------
A. Test clean masks versus controlled perturbations FIRST.
Current behavior: about 80% of masks get smooth grow/shrink/wobble perturbations.
Provide independent options, for example:
    --mask_perturb_prob, --mask_shift_mm, --mask_noise_scale
These are proposed options, NOT currently executable CLI flags.
Start with a clean-mask arm (probability 0), preserving ordinary spatial transforms.
Then test a 50% clean / 50% mildly perturbed arm as a candidate setting.
For the mild arm, a shift range of +/-1 mm is a starting experiment, not an optimum.
Gaussian wobble is not strictly bounded by the shift range; explicitly bound the
combined displacement if a hard maximum is desired.
Estimate realistic error patterns using out-of-fold training predictions.

B. Sample correctable errors, not only arbitrary mask surface.
Current sampling: 75% M0 edge and 25% anywhere in the padded ROI.
Pilot a mixture such as:
    25% editable false negatives; 25% editable false positives;
    50% ordinary boundary locations, including already-correct boundaries.
Use training annotations only. If an error category is absent, redistribute
samples to ordinary boundary locations. Keep validation/inference sampling free
of annotations. These fractions are experimental, not requirements.
Log editable-voxel count and correctable-error count per sampled patch.
Do not train exclusively on mistakes: the model must learn when not to edit.

C. Treat a lower learning rate as a controlled experiment.
Compare 1e-3 against 2e-4 or 3e-4 with the same data, schedule and update budget.
Do not claim 1e-3 caused this result: the log has no instability or divergence.
Log effective learning rate, residual magnitude, gate values and gradient norm.
Select on validation, not test. Do not change learning rate, augmentation,
loss and architecture together and attribute any gain to frequency.

D. Keep masked Dice+BCE as the reference objective.
Only after data diagnostics, test ONE additional objective at a time:
- A small distance/surface auxiliary term for accurate boundaries.
- A small correction penalty on already-correct editable training voxels.
- Per-patch normalization if pooled editable voxels over-weight particular patches.
Normalize terms and log each magnitude. Excessive preservation penalties can
produce identity; excessive boundary weighting can damage region overlap.
Ground-truth edges must be training targets, never input channels at inference.

6. HOW TO MAKE THE FREQUENCY BRANCH ADD DEMONSTRABLE VALUE
--------------------------------------------------------------------------------
The current design already supplies LLL context and signed high-frequency bands.
Do not assume more frequency modules will help. Test these explanations in order:

A. Does frequency beat a matched spatial refiner?
Run the spatial twin with the same input masks, sampling, augmentation, optimizer,
update count, validation procedure and seeds. Use identical initialization for
shared layers where practical; the same random seed alone does not ensure this
because constructing the learned split consumes random numbers.
Report exact parameter counts; the spatial split adds a small number of parameters.
Compare frequency minus spatial directly on paired patients.

B. Is high-frequency detail actually being used?
Controlled ablations: all bands, LLL-only (detail zeroed), high-frequency branch
zeroed, context-detail fusion gate removed. Distinguish retrained ablations from
inference-only perturbation probes; the latter can be out-of-distribution.
Inspect where correct edits coincide with useful MRI boundaries, not only gate maps.
A gate visualization alone does not establish causal usefulness.

C. Does Haar help beyond fixed downsampling?
If the primary comparison is promising, add a fixed voxel-unshuffle or another
fixed orthonormal transform control. This separates the benefit of a fixed
representation from Haar's particular context/detail organization.

D. Add adaptive detail suppression only if errors implicate noisy bands.
Candidate modification: bounded context-conditioned gains or soft thresholds for
individual bands, keeping low-frequency anatomy available and preserving signed
coefficients. Compare with the existing fusion gate at matched capacity.
This may suppress noise, but can also remove small-lesion detail; ablate it.
Do not force every strong high-frequency edge to become a tumor boundary.

E. Check scale and shift sensitivity before more expensive architecture changes.
Strided Haar is sensitive to one-voxel phase changes. Measure prediction changes
under small translated inputs, align outputs back, and evaluate only valid regions.
If phase sensitivity is substantial, test phase augmentation or shift averaging
and report its inference cost. A second wavelet scale is justified only if error
analysis indicates missing context/detail scale; compare a spatial multiscale twin.

--------------------------------------------------------------------------------

  Freeze the source S3f masks and record the exact code/environment/input hashes.

Stage 1: inexpensive diagnosis
  Compute the editable-band upper bound. Inspect representative real errors.
  Add validation edit-quality logs. No official-test evaluation during tuning.

Stage 2: pilot matched baselines
  Run spatial and frequency twins using the corrected data pipeline.
  Establish clean-mask baselines, then vary perturbation or sampling one at a time.
  Use a fixed pilot horizon (e.g. 18-24 epochs) and the same scheduling convention.
  A shortened schedule has a different cosine decay from a truncated 60-epoch run;
  record this rather than presenting those runs as identical optimization.
  If testing LR, vary it separately. Keep the stopped run as historical evidence.

Stage 3: full confirmation
  Extend promising configurations to a predeclared full schedule.
  Repeat the strongest spatial/frequency comparison across multiple seeds.
  Select the final method using validation, freeze it, then evaluate test once
  for that final comparison. Disclose earlier test-set use in the project.

Success criteria:
- Refined model improves over its EXACT source M0 baseline.
- Frequency improves over the matched spatial model, not merely M0.
- Paired patient-level confidence intervals, seed variability, boundary metrics,
  lesion misses and severe regressions support the claimed benefit.
- Report runtime and memory costs for any additional gain.
- If both twins improve equally, claim useful refinement, not a proven frequency
  advantage. If neither improves, revisit input errors and headroom before adding text.
There is no guaranteed numeric Dice target or acceptable edit-count target.
