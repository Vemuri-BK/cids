1. CURRENT BASELINE & WHERE THE REMAINING ERROR LIES
--------------------------------------------------------------------------------
Current S3f (SegResNet-100 -> SAM-S2b -> 13-Clue Memory Jury):
  - Validation (120 cases): Dice = 0.7742 | NSD = 0.8204 | HD95 med = 3.00 mm | Missed = 3
  - Official Test (306 cases): Dice = 0.7495 | NSD = 0.7987 | HD95 med = 3.32 mm | Missed = 10
  - Candidate Selection Ceiling (Oracle): Val = 0.8120 (+0.0378 gap) | Test = 0.7901 (+0.0406 gap)
  - On well-localized cases (Dice >= 0.5): Mean Dice is already 0.8402 (Val) / 0.8200 (Test).

Why S7 Refiner (v1-new / v2) only reached Val 0.7752 / 0.7761 (+0.001 to +0.002):
  1. Missing Checker Map (`sam_prob`): S7 only sees `M0` (which is `seg_prob > 0.5`) and `seg_prob`
     (redundant). SAM-S2b's boundary probability map `sam_prob` was discarded before S7.
  2. Band-Only Soft Dice Denominator: `dice_bce` computes Soft Dice only on `allow > 0.5`, ignoring
     the frozen tumor core (`M0 & ~allow`). Because the outer 8 mm shell has larger surface area
     than the inner 8 mm shell, background outnumbers foreground in the band, biasing the refiner
     to shrink/erode tumors on ambiguous margins (`ispy2_775346`, `ispy2_788149`, `duke_132`).
  3. Synthetic Mask Perturbation (`p_perturb = 0.8`): 80% of OOF training masks are corrupted by
     Gaussian SDF wobble (+/- 2 mm), teaching geometric smoothing rather than MRI edge alignment.
  4. Unfiltered High-Frequency Noise (`HHH` band): `det_proj` mixes all 21 high-frequency channels
     (including noisy `HHH`) with a 3x3x3 conv, memorizing training texture (`s7_learn_test`:
     fitted +0.050, unseen -0.035).

CHANGE 2: Post-Hoc Calibration & Safety Gate on Existing S7 Checkpoints (GPU, ~2 min)
New Script: scripts/s7_calibrate.py (and flags in scripts/s7_refine.py)
--------------------------------------------------------------------------------
Why:
  In `v1-new`, 77 val cases improved vs 40 worsened (Wilcoxon p = 0.002), but 3 outlier cases
  lost -0.07 to -0.10 Dice due to excessive voxel removals.

What to add:
  1. Confidence threshold `--tau_edit` (default 0.0; test {0.0, 0.25, 0.5, 0.75, 1.0} in logit space):
     A voxel in the `allow` band is only flipped from `M0` if `|z| > tau_edit`.
  2. Case-level volume-erosion safety cap `--max_rem_frac` (e.g., 0.12):
     If removals `(M0 & ~r).sum() > max_rem_frac * M0.sum()`, only keep the top most-negative
     `z` removals up to `max_rem_frac * M0.sum()`.
  3. Choose `(tau_edit, max_rem_frac)` strictly on Validation (120 cases).

CHANGE 3: Full-ROI Soft-Dice Loss + Edit-Preservation Penalty in S7 Refiner
File: scripts/s7_refine.py (lines 58-94)
--------------------------------------------------------------------------------
Why:
  Computing Soft Dice only inside `allow > 0.5` ignores the frozen tumor core (`M0 & ~allow`) and
  biases the refiner toward shrinking the mask.

What to add in `scripts/s7_refine.py`:
  Add `--loss full_dice_bce` and `--lam_stay 0.05`:
  ```python
  def full_dice_bce(z, y, x, lam_stay=0.05):
      """Full-ROI Soft Dice (frozen core = M0, editable band = sigmoid(z)) + active-band BCE + stay penalty."""
      m0 = x[:, 3:4]
      allow = x[:, 5:6]
      band = allow > 0.5
      if not band.any():
          return z.sum() * 0.0
      # Effective full-patch probability: exact 0/1 outside allow band, sigmoid(z) inside allow band
      p_full = (1.0 - allow) * m0 + allow * torch.sigmoid(z)
      dims = (1, 2, 3, 4)
      inter = (p_full * y).sum(dims)
      den = p_full.sum(dims) + y.sum(dims)
      dice = (1.0 - (2.0 * inter + 1.0) / (den + 1.0)).mean()
      # Active-band BCE
      bce = F.binary_cross_entropy_with_logits(z[band], y[band])
      # Small L1 penalty on logit residual r = z - z0 inside allow band to prevent speculative edits
      z0 = (2.0 * m0 - 1.0) * math.log(3.0)
      stay = (allow * (z - z0)).abs()[band].mean()
      return dice + bce + lam_stay * stay
  ```

CHANGE 4: Dual-Teacher Inputs (`seg_prob` + `sam_prob` + Disagreement) for S7
Files: scripts/s3f_jury_masks.py, scripts/s3g_oof_train_masks.py, cids/refine/data.py
--------------------------------------------------------------------------------
Why:
  Where SegResNet (`seg_prob`) and SAM-S2b (`sam_prob`) agree, the boundary is already reliable.
  Where they disagree (`|seg_prob - sam_prob|` is high inside the 8 mm band), the refiner can use
  3D Haar MRI edges to arbitrate between Finder and Checker.

What to change:
  1. In `s3f_jury_masks.py` and `s3g_oof_train_masks.py`:
     Save `sam` (uint8, max of `d["prob"] * 255` over the kept candidates) inside `cases/<cid>.npz`
     alongside `seg` and `lab`.
  2. In `cids/refine/data.py` (`prepare_case` and `roi_channels`):
     When `sam_prob` is present in `d.files`, append 3 extra channels (`extra_ch = 3`):
     `[seg_prob, sam_prob, np.abs(seg_prob - sam_prob)]`.

CHANGE 5: Subband Gating & `freq_no_hhh` Mode in `BoundaryRefiner`
File: cids/refine/model.py (lines 41-88)
--------------------------------------------------------------------------------
Why:
  The 3-axis high-pass `HHH` wavelet band in breast DCE-MRI is dominated by noise/BPE speckle,
  causing overfitting in `det_proj`.

What to change in `cids/refine/model.py`:
  1. Allow `mode in ("freq", "freq_no_hhh", "freq_lll", "spatial")`.
  2. In `mode == "freq_no_hhh"`, zero out band 7 (`HHH`) while keeping `LLL` (context) and the 6
     directional 1-axis/2-axis edge bands (`LLH, LHL, LHH, HLL, HLH, HHL`).
  3. Add a learnable 7-element subband gate `self.band_logit = nn.Parameter(torch.zeros(7))`
     (scaling each high-frequency subband by `2 * sigmoid(band_logit)` before `det_proj`), providing
     an interpretable subband importance readout just like `SamFreqAdapter`.
